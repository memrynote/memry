## Recording checklist

Before recording:

- Use fake/demo data only.
- Hide system notifications.
- Use dark mode.
- Set app zoom to 110–125% so text is readable on mobile.
- Keep the cursor movement slow.
- Do one clean take; do not over-edit.

Recommended tools:

- Screen Studio: best polished product demo quickly.
- CleanShot X: quick screen recordings and screenshots.
- OBS: free, more manual setup.

Export:

- MP4
- 1080p
- 30fps
- 30–45 seconds
- Captions burned in if possible
