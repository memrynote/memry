# Glossary

Terms for the Tauri v2 desktop epic (#3517). Decisions live in [docs/adr/0001-desktop-on-tauri-v2.md](docs/adr/0001-desktop-on-tauri-v2.md).

- **Vault**: the folder of notes, journal files and attachments a user opens, with its `.memry/` folder. Owner: `crates/memry-core`.
- **Core** (`memry-core`): the Rust crate that owns sync, crypto, CRDT, storage, markdown conversion and domain rules, shared by iOS and desktop. Owner: `crates/memry-core`.
- **Shell**: a native app around the core that holds UI and platform capabilities but no domain decisions. The desktop shell is Tauri v2, the iOS shell is SwiftUI. Owner: `apps/desktop-tauri`, `apps/ios`.
- **Desktop crates**: `memry-desktop` (OS services, no tauri dependency) and `memry-ml` (native ML libraries), which never depend on `tauri`. Owner: `crates/memry-desktop`, `crates/memry-ml`.
- **Sidecar** (`memry-ml-worker`): the process that runs OCR and pdfium, so a hung native call is killed without taking the app down. Owner: `crates/memry-ml`.
- **Pending ratchet**: the list of desktop API entries not yet ported, which can only shrink. Owner: `apps/desktop-tauri/src-tauri/agent-mcp/desktop-api-pending.json`, Step 28 (#3545).
- **`memry-tauri`**: the Tauri bin crate whose adapters parse arguments, call one service method and map the error. Owner: `apps/desktop-tauri/src-tauri`.
- **Converter**: the code that turns a note body into markdown and back. The Rust port in `crates/memry-core/src/markdown/` becomes the owner; the frozen TypeScript converter stays the vector oracle. Owner: `crates/memry-core/src/markdown/`.
- **Markdown seed**: the core module that parses markdown into a document for the writes of protocol section 12.1.0. Owner: `crates/memry-core/src/crdt/markdown_seed/`.
- **Core databases**: `<vault>/.memry/core/data.db` and `index.db` under the memry-core schema. Owner: `crates/memry-core/src/storage/`.
- **Electron data**: the Electron `<vault>/.memry/data.db` and `index.db`, read once by the first-launch migration and never written. Owner: `apps/desktop` until the cutover.
- **App data dir**: the Tauri app data directory that holds app state outside any vault. Owner: `apps/desktop-tauri/src-tauri`.
- **Cutover**: the step that deletes the Electron app, `packages/app-core`, Playwright and the Electron-only tools. Owner: Step 43 (#3560).
- **Frozen Electron**: the state of `apps/desktop` until the cutover, where only critical bug fixes land. Owner: `apps/desktop/AGENTS.md`.
- **Dual-renderer rule**: a critical renderer fix lands in both `apps/desktop/src/renderer` and `apps/desktop-tauri/src/renderer` in the same PR until the cutover. Owner: `apps/desktop/AGENTS.md`.
- **Command**: a Rust function the renderer calls, with TypeScript types generated by tauri-specta. Owner: `apps/desktop-tauri/src-tauri`.
- **Event**: a message from Rust to the renderer, typed through tauri-specta. Owner: `apps/desktop-tauri/src-tauri`.
- **Channel**: a binary stream between Rust and the renderer, used for Yjs updates and files. Owner: `apps/desktop-tauri/src-tauri`.
- **Test command**: a command that exists only for end-to-end tests. Owner: `apps/desktop-tauri/src-tauri`.
- **Bridge feed**: an update feed that lets installs still running electron-updater reach the Tauri build. Owner: release pipeline, Step 39 (#3556).
- **Velopack pack**: the Velopack update package built for each OS. Owner: release pipeline, Step 39 (#3556).
- **Parity row**: a named Electron feature a step ports, listed at the end of each step issue. Owner: the epic, #3517.
