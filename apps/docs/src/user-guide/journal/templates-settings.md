# Journal Templates & Settings

Pick a starting template for new entries — one for every day, or a different one per weekday — and toggle the stats footer.

<!-- screenshot: journal settings panel -->

Open from [Settings → Journal](/user-guide/settings#journal), or right-click **Journal** in the sidebar and choose **Journal Settings…**.

## Default Template

Pick any [template](/user-guide/templates) (built-in or custom). New journal entries are seeded with that content.

Useful for prompts like:

- Daily reflection (gratitude, intentions, retro)
- Standup template (yesterday / today / blockers)
- Mood / energy log

If the template uses date variables, they're filled in for the current entry's date.

## Per-Day Templates

Expand the per-day row to choose a template for each day of the week — a standup on Monday, a weekly review on Friday, a longer reflection on Sunday.

- A day set to **Use default** falls back to the default template above. The row shows what that resolves to, so you can see what each day will actually open with.
- Days are bound to the actual weekday, not to a position in the week. Changing your first-day-of-week preference reorders the rows; it never moves a template onto a different day.
- If a template a day points at is deleted, the row is flagged and that day opens blank until you pick another one.

Templates apply to any entry that doesn't exist yet, including past and future dates you navigate to.

## Stats Footer

Toggle the footer that displays word count, character count, and entry counts at the bottom of the writing column.

## What Syncs

Your template choices — the default and the per-day overrides — sync across your devices, so the same day opens with the same prompt everywhere. Each day syncs independently: setting Monday on one machine and Tuesday on another keeps both.

Existing choices aren't pushed out until you change them, so upgrading won't overwrite what another device already had.

Layout preferences like the stats footer stay device-local, so a laptop and a desktop can differ.
