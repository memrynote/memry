# Journal Templates & Settings

Pick a default starting template for new entries and toggle the sidebar panes.

<!-- screenshot: journal settings panel -->

Open from [Settings → Journal](/user-guide/settings#journal).

## Default Template

Pick any [template](/user-guide/templates) (built-in or custom). New journal entries are seeded with that content.

Useful for prompts like:

- Daily reflection (gratitude, intentions, retro)
- Standup template (yesterday / today / blockers)
- Mood / energy log

If the template uses date variables, they're filled in for the current entry's date.

## Sidebar Visibility

Toggle which panes appear in the journal sidebar:

| Toggle        | Shows                                |
| ------------- | ------------------------------------ |
| Show Schedule | Calendar events for the focused date |
| Show Tasks    | Tasks due that day                   |

Each toggle is independent. Turn them on as you find them useful.

## Stats Footer

Toggle the footer that displays word count, character count, and entry counts at the bottom of the writing column.

## Why These Live in Settings

Journal preferences are personal — they don't sync between devices by default. If you prefer a different layout on a laptop vs desktop, that's supported automatically.
