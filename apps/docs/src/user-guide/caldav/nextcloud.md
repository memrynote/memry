# Nextcloud (CalDAV)

## Create an App Password

In Nextcloud, open **Personal settings** → **Security**, and under **Devices & sessions** create
a new app password named "memrynote". Copy it.

## Connect

In [Settings → Calendar](/user-guide/settings#calendar) → **CalDAV**, pick **Nextcloud** and type
your server's name, such as `cloud.example.com`. memrynote uses
`https://cloud.example.com/remote.php/dav/`. Enter your Nextcloud username and the app password,
and press **Test connection**.
