# mailbox.org (CalDAV)

## Password

If you use two-factor sign-in with mailbox.org, create an application password in its settings
and use it here. Otherwise your mailbox.org password works.

## Connect

In [Settings → Calendar](/user-guide/settings#calendar) → **CalDAV**, pick **mailbox.org**, enter
your mailbox.org address and the password, and press **Test connection**.
