# Zoho Calendar (CalDAV)

## Create an App Password

If you use two-factor sign-in with Zoho, create an application-specific password in your Zoho
account's security settings and use it here. Otherwise your Zoho password works.

## Connect

In [Settings → Calendar](/user-guide/settings#calendar) → **CalDAV**, pick **Zoho**, enter your
Zoho email address and the password, and press **Test connection**.
