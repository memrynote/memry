# Filters & Views

Filter the inbox by content type and switch between Inbox / Triage / Archived / Health views.

<!-- screenshot: inbox with content type filter chips active -->

## The Four Views

| View | What it shows |
| --- | --- |
| **Inbox** | Pending items waiting to be triaged |
| **Triage** | A focused, card-based workflow (see [Triage Mode](/user-guide/inbox/triage)) |
| **Archived** | Items you've already processed |
| **Health** | Failed sync jobs and items needing attention (see [Health](/user-guide/inbox/health)) |

Switch from the tabs at the top of the inbox view.

## Content Type Filters

A row of icon buttons filters by content type:

| Icon | Type |
| --- | --- |
| 🔗 | Links |
| 📝 | Notes |
| 🖼️ | Images |
| 🎤 | Voice |
| 🎞️ | Video |
| ✂️ | Clips |
| 📄 | PDFs |
| 💬 | Social |

Click any chip to filter to that type. Click again to remove.

## Layered Filters

Multiple types can be active at once — the result shows items matching **any** active type. Useful for batches:

- Links + Clips — read web stuff
- Voice + Notes — process spoken / written captures
- Images + PDFs — visual reference review

## Search Within Inbox

Use the inbox search bar to filter the current view by free-text. Combines with content type filters:

> "links containing OAuth" = link filter on + search "OAuth"

## Stale Indicator

Items older than the **Stale Inbox Days** setting show a stale chip. Stale doesn't change behavior — it's a visual reminder for periodic clean-ups. Configure the threshold in [Settings → Tasks](/user-guide/settings#tasks).

## Sorting

The inbox sorts by capture time, newest first, by default. The header sort menu offers:

- Newest first
- Oldest first
- By type
- By source

## Persistence

Active filters and view persist across app restarts (if **Restore Session** is on). Reopening the inbox is exactly where you left off.
