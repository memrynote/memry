# Roadmap

memrynote is moving toward a first public release. This page tracks direction, not a release
promise.

## Near Term

- Stabilize the desktop app
- Keep local-first note, journal, task, and project flows reliable
- Harden encrypted sync and device linking
- Improve docs for contributors and early testers

## Later

- Mobile apps
- Browser extension for quick capture
- Local-first AI search
- Shared vaults
- Plugin system
- Self-hosted sync server option

## Release Notes

Release notes live in the repository and will become more user-facing as packaged builds
are published.
