# Features Overview

A high-level map of what memrynote does. Each section links to dedicated pages in the [User Guide](/user-guide/notes/editing).

## Notes

Rich-text editing with BlockNote, wiki links, backlinks, properties, attachments, audio blocks,
reminders, and version history.

→ [Notes](/user-guide/notes/editing)

## Journal

A daily writing space with calendar navigation (day / month / year), heatmap, stats, and templates.

→ [Journal](/user-guide/journal/daily-entries)

## Tasks & Projects

Tasks live alongside notes and filed audio. Multi-view (list / kanban), filters, saved filters,
subtasks, recurrence, bulk actions, related items, and drag-drop. Group tasks under projects with
custom statuses.

→ [Tasks](/user-guide/tasks/list-vs-kanban) · [Projects](/user-guide/projects)

## Inbox

A capture surface for links, files, voice, video, PDFs, clips, and social posts — with a focused triage flow, snooze, and a health view.

→ [Inbox](/user-guide/inbox/capturing)

## Calendar

Day / week / month / year views over events and date-bound tasks. Optional Google Calendar integration.

→ [Calendar](/user-guide/calendar)

## Search

A global command palette (<kbd>Cmd</kbd>+<kbd>K</kbd>) with scoped filters, tag search, recents, and (when AI is enabled) semantic ranking.

→ [Search](/user-guide/search)

## Command Line

The desktop app ships a `memrynote` CLI that can be enabled from Settings with a selected default vault. It can initialize and open a vault, create and update notes, manage note attachments and exports, write journal entries, manage tasks/projects, capture inbox items, and search from scripts or a terminal.

→ [Command Line](/user-guide/cli)

## Canvas

Infinite boards with ink, shapes, and live cards for notes, tasks, and events. Opt-in under Settings → Features.

→ [Canvas Overview](/user-guide/canvas/overview)

## AI Features

Inline AI menu in the editor, Agent Chat with approval-gated vault writes, local OpenAI-compatible
agent providers, on-device embedding model for semantic search, voice transcription, a localhost MCP
server for vault tools, and pluggable inline providers (Ollama / OpenAI / Anthropic).

→ [AI Features](/user-guide/ai/inline-menu) · [Agent Chat & MCP Server](/user-guide/ai/agent-mcp)

## Sync & Devices

End-to-end encrypted sync, multi-device linking with QR + linking code, recovery phrase, and key rotation.

→ [Sync & Devices](/user-guide/sync/how-sync-works)
