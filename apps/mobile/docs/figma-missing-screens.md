# Memry Mobile — missing screens

Audit date 2026-08-27. Figma file `12AJO1nkTbStIJi5vWDfAq`, 109 artboards at the time of the audit.

Re-counted from `figma.root.children` on 2026-08-27 after the Tier 1–3 boards landed: 14 pages,
174 top-level frames, of which 7 are `00 · Foundations` spec boards and **167 are screens**. Tier 1–3
(rows 1–65) are drawn. Tier 4 (rows 66–79) and the two Foundations boards (rows 80–81) are not.
`ui-design.md` still says 108 and this file still said 109; neither number is current.

Two independent audits produced this. One compared the inventory against `specs/001-mobile-app/spec.md`
functional requirements and edge cases. One compared it against what the shipping desktop app actually
lets a user do, with a repo path as evidence for every row.

Rows are deduplicated across both audits and ranked by user impact. Screen numbers continue the existing
per-page numbering. Nothing here is listed as out of scope for v1 in the spec.

## Corrections to carry into the design prompt

A bookmark is an internal item reference, not a web URL. `packages/contracts/src/bookmark-types.ts`
defines the item types as note, journal, task, folder, tag, image, pdf, audio, video, canvas and file.
Design the bookmarks screen as a reorderable list of vault items with type icons, never as a URL list
with favicons.

Desktop has no trash, no note duplicate and no note pin. Do not design mobile screens for them.
Bookmarks fill the pin role.

## Explicitly not proposed

Trash and restore, note duplicate, note pin and favourite. None exists on desktop.
`contexts/tabs/reducers/tab-crud-reducer.ts` confirms deletes go to the OS trash with no in-app undo,
and bookmarks fill the pin role. Agent Chat, importers, semantic search, canvas editing, system
share-sheet capture, instant push sync, biometric app lock and Android are out of scope for v1 per the
spec, and only appear above inside screen 58, which discloses their absence rather than implementing them.
