## New Features

- 📂 Reveal a folder — open any folder from Memry directly in your operating system's file manager.

## Improvements

- 🔗 Backlink backfill — links to a note that doesn't exist yet now show up as backlinks once you create that note.

## Fixes

- 🔒 Agent-only vault writes — writes through the local MCP server now require a running Agent turn, so an outside client can no longer create, edit, or delete anything in your vault.
- 🪟 Maximized window remembered — Memry reopens maximized if that's how you left it.
- ↔️ Back and forward in the same tab — navigating within a tab is now recorded in its history, so back and forward work as expected.
- ⌨️ Switch-vault shortcut — the shortcut now works while your cursor is in the editor.
- 📝 Template insertion — inserting a template from the note menu keeps its anchor position correct.
- 🔐 Vault ownership message — Memry now tells you clearly when the vault you have open isn't part of your account.
- 💳 Clearer vault-limit message — hitting your vault limit no longer shows a misleading "a paid plan is required" error.
- 🎨 Safer custom icons — icons loaded from a URL are sanitized, including those chosen from the context-menu picker.
- 🛡️ Signed Windows installer — the Windows installer is now properly signed, avoiding security warnings during install.
- ⬇️ More reliable Windows updates — the update hand-off to the Windows installer is now visible and retries its download if it fails.
