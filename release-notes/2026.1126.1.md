## New Features

- ✨ Slash menu converts the current line — Choosing a block type from the slash menu now turns the line you're on into that block, so you no longer get a new block below it.

## Improvements

- ⚡ Lighter local embedding — Local embedding now stays off your Mac's performance cores and skips notes that haven't changed, so the app stays more responsive.
- 🚪 Faster vault closing — Closing or switching vaults no longer hangs while it waits on note storage.
- 📤 Leaner attachment uploads — Memry no longer re-sends attachment chunks the server didn't ask for and no longer retries attachments it has already rejected.
- 🪟 Clearer Windows folder errors — When Windows refuses to delete a folder whose name ends in a dot or space, you now see a readable explanation.

## Fixes

- 🛡️ Safer app updates — Updates no longer replace a working installation before the new one is fully in place.
- ↩️ Slash menu cleanup — Using the slash menu no longer leaves a stray space behind, and undo now returns the line to how it was before.
- 🌏 Korean and IME typing — Korean text stays whole when a #tag turns into a chip, and Enter and Escape no longer interrupt text you are still composing.
- 🏷️ Journal tags and properties merge correctly — Tags and properties edited on different devices now combine instead of overwriting each other.
- 🖼️ Journal pictures sync reliably — Pictures in a journal day now download when you open the day or when another device adds them, and keep their names when days are merged.
- 📓 Journal edits are kept — Journal days edited while the app was closed now sync when the vault opens, and new journal entries finish syncing before the app quits.
- 🗑️ Edits survive remote deletes — A note or journal edit made outside the app, or not yet picked up by the app, is no longer lost when a delete arrives from another device.
- 🔠 Notes with case-only name differences — Notes whose names differ only in capital letters now keep their own content, headers, history and offline edits through renames, moves, deletes and sync.
- 📁 Folder moves and renames keep your notes — Slow or interrupted folder moves no longer lose notes, and edits and link updates made after a folder rename land in the right place.
- 📎 Attachments and files download when needed — Opening a note now downloads its files even when automatic downloads are off, and downloads that were interrupted pick up again correctly.
- 🔀 Binary file conflicts handled safely — When another device replaces a file you also changed locally, your version is now kept as a conflict copy.
- 💬 Comments keep your latest text — Comment actions no longer save an older copy of the note body.
- 🪟 Pasted attachments on Windows — Pasted attachments are no longer indexed as notes on Windows, and empty pastes are ignored.
- 👀 External file changes are noticed — The vault watcher now ignores only the app's own writes, so changes you make in other apps are always picked up.
- 🔗 Unlinked mentions — Linking an unlinked mention now changes the note file only in the spot you linked.
- 🔐 Sync state survives sign-out — Signing out or running an emergency wipe now keeps the device's own sync bookkeeping, which prevents problems the next time you sync.
