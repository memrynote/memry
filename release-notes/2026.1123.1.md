## Improvements

- ⚡ Faster first sync — A new device now downloads your vault in larger bundles and builds search and lists faster, so it gets ready sooner.
- 🧵 Smoother app during sync — Notes are decrypted in the background, so the app stays responsive while large vaults sync.
- 📋 Lighter list refreshes — Note lists refresh more efficiently while many notes are being written during sync.
- 📶 Sync recovers from network drops — If your connection drops during first sync, it pauses and picks up where it left off instead of starting over or leaving gaps.
- 🔁 Interrupted first syncs resume — If Memry is closed during a first sync, the sync continues next time without starting from scratch.
- 📎 Faster attachment downloads — Attachments are now requested in batches, so files arrive quicker.
- 🚦 Better handling of busy servers — When the sync server asks Memry to slow down, it waits and retries instead of dropping data.

## Fixes

- 🏷️ Renamed notes keep their identity — Notes renamed or moved outside Memry, including changes only to capitalization, keep their links and history.
- 🔠 Notes with the same name in different capitalization — Deleting, renaming or moving one of these notes no longer affects the other's file or content.
- 📄 Non-text files stay intact — PDFs, images and other non-text files are no longer overwritten with text, and files that were already damaged are restored from sync.
- 🗑️ Deleted items stay deleted — Items deleted on another device no longer come back from pending edits, and edits to them are cleaned up properly.
- 📓 Journal fixes — A deleted journal day that you create again starts empty, and journal tags now save and merge correctly.
- 🏷️ Tags and properties stick — Edits to tags and properties are no longer undone by a background sync.
- 🧹 Duplicated note content removed — Note content that an earlier version had copied twice is now cleaned up automatically.
- ✍️ Offline editing — Notes that have never synced can be edited offline, and offline edits now merge without losing changes made on other devices.
- 🔐 Clearer behavior when signed out — If your session expires, notes that haven't finished syncing open read-only with a prompt to sign in, and the editor unlocks once your vault key is available again.
- ⚙️ Settings sync reliably — Settings changes that the server missed are sent again so all your devices stay in sync.
- 🆕 Cleaner setup on a new device — A new device no longer sends data back to the server during its first download.
- 🔄 Pending changes sent after reconnecting — Changes held while you were offline or while sync was paused are sent once you reconnect.
- 🔗 Accurate link updates — Link changes that come from sync are now labeled as sync changes rather than your own edits.
