## New Features

- 🏠 Default Tasks project — set the project Tasks opens on directly from the project dropdown (hover a project and click the home icon) or from a project's edit dialog.
- 🧩 Task details in place — clicking the arrow on a task in a note or journal now opens its details panel right there, so you can add subtasks and edit properties without leaving the note.
- 🗂️ Canvas sections bound to tags or properties — tie a section to a tag or property value so dropping a card into it tags the note or sets the value (with undo), and "Lay out by property" sorts a board into one section per value.
- 🔗 Link and tag from the graph — hold Alt (Option on macOS) and drag one note onto another to link them, or right-click a note for Link to…, Add tag…, and Remove link, with undo available for each change.

## Improvements

- ⚡ Lighter launch — memory use at startup is lower, especially on the Home screen.

## Fixes

- 🔀 Vault switching fixes — picking a vault no longer leaves an invisible menu behind, and stray inputs (tilt-wheel clicks, Shift+scroll, AltGr typing, or the vault shortcut while Settings is open) no longer switch vaults.
- 🔖 Home Bookmarks cleanup — the widget no longer shows bookmarks for deleted notes, and folder and tag bookmarks now open correctly.
- 🗑️ Folder deletions sync — folders deleted on another device are now removed on this one.
- 📅 All-day task dates preserved — all-day task dates are now kept across calendar sync.
