## New Features

- 💬 **Ask Memry how-to questions** — Agent Chat can now answer questions about using Memry, drawing on the built-in user guide.
- 🛟 **Database recovery** — If Memry detects that its local database is corrupted, it now offers a recovery option that runs only after you confirm.

## Improvements

- ⚡ **Faster first sync** — Your note content now downloads in bundles during first sync, so a new device is ready sooner.
- 📤 **Quicker uploads** — Note changes are now sent to the sync server in batches, so large vaults upload faster.
- 📝 **Notes load when you open them** — Notes that haven't synced yet now download as soon as you open them, and the rest keep syncing in the background.

## Fixes

- 🧠 **Search indexing runs in the background** — Rebuilding the search index now continues from where it stopped and runs at low priority, so it no longer slows down the app.
- 🏷️ **Multi-word projects and tags** — When autocomplete fills in a project or tag name with more than one word, Memry now reads it back correctly.
- 📔 **Journal editing** — The journal editor no longer closes or resets when your first save creates a new entry.
- 🔄 **Interrupted first sync resumes** — If a first sync is interrupted, it now picks up where it left off and doesn't download finished parts again.
- 📎 **More reliable attachment downloads** — Interrupted attachment downloads now resume, and missing attachments are retried automatically.
- 🗂️ **Settings kept after recovery** — Recovering a corrupted database now keeps your vault's identity and settings.
- 🩹 **Recovery during use** — Memry now offers database recovery when corruption is found while you're using the app, not only at startup.
