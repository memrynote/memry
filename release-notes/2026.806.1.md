## New Features

- 🎨 Spatial canvas — arrange notes, tasks, and calendar events on an infinite Excalidraw board, now on by default for everyone.
- 🗂️ Canvases live in your vault — boards are saved as plain .excalidraw files you can open with any compatible app.
- 🖱️ Drag onto the canvas — drop notes, tasks, and events straight onto a board, including several at once.
- 🔍 Add card picker — search your notes, tasks, and events or create a note in place, with results rendered the way the rest of the app shows them.
- ✍️ Live canvas cards — cards show fully rendered content with images, checkboxes, and formatting, and you can double-click to edit in place.
- 🤖 Agents can draw — the assistant can add shapes, text, bound arrows, and frames to your canvases.
- 🏷️ Tag categories and tag hub — organize tags into categories and browse everything on a dedicated tag page.
- 🔗 Relation properties — link a note to other notes, files, tasks, and events through a property.
- 📁 Project property for notes — assign a note to a project from its properties, and see it as a clickable project pill in folder views.
- 📅 Project on events — pick a project for a calendar event directly in the event form.
- 📝 Template authoring — build and edit templates on the full note surface.
- ☁️ Templates sync — your custom templates now follow you across devices.
- 🔖 Bookmarks and reminders sync — dismissing or snoozing a reminder on one device stops it firing on the others.
- 🗃️ Chrome-style tab bar — tabs compress to icons and then scroll instead of shrinking away.
- 🖼️ Obsidian image embeds — wiki-style image embeds work in both import and the editor.
- 🆘 F1 for docs — press F1 or use Help → Documentation to open the online docs.

## Improvements

- 🔒 Calendar privacy controls — agent access to your Google Calendar events is now gated on your explicit consent and kept out of AI surfaces.
- ⬇️ Smarter updates — updates are checked more often, can download silently if you opt in, and show release notes in their own tab.
- 🌍 Complete translations — all 32 languages are now fully translated, with long-standing wording defects fixed.
- 💬 Better feedback flow — the in-app feedback form shows exactly what it sends before you send it.
- 🚀 Faster vault opening — embeddings are built in the background so opening a vault no longer hangs.
- 📇 More tolerant indexing — notes with broken YAML frontmatter or no content are still indexed and searchable.
- 🧹 Cleaner uninstall — `brew uninstall --zap` now removes app data, settings, caches, and logs while leaving your vault untouched.
- 📦 Tidier app data — settings, logs, and stored data moved to a `memrynote` folder and migrate automatically on first launch.
- 🎯 Consistent icon pickers — note, folder, and project icon pickers now use the same picker and stay on screen.

## Fixes

- ☁️ Notes no longer sync as "Untitled" — note titles, embedded images, and PDFs now reach your other devices after an edit.
- 📎 Attachments survive sync — note attachments now transfer correctly between devices, even when sync is starting up.
- 🔁 Sync recovers on its own — hung requests, retry budgets, and dropped updates no longer leave sync stale until you restart the app.
- ✅ Tasks reappear after project deletion — tasks created or edited elsewhere no longer go missing or re-download endlessly.
- 🔐 New-device setup — the vault download step no longer gets stuck when linking a new device.
- 📥 Inbox conversion — turning an inbox item into a task no longer fails when sync is unavailable, and filed files open in the viewer with their tags intact.
- 🖼️ Images render again — note-relative and Obsidian-style image paths resolve against your vault instead of showing as broken, and stay portable when you save.
- 📄 PDF page navigation — multi-page PDFs embedded in a note can be paged through again.
- 📂 Import brings media along — markdown import now carries images and attachments from shared media folders.
- 💬 Comment fixes — comments stay put through a resync, the review flyout stays open while editing, the @-mention picker is no longer clipped, and image and PDF attachments open in-app.
- 📅 Calendar popover — the quick-create popover stays inside the window, and promoting an event asks for confirmation when agent access is off.
- 🏷️ Live tag sidebar — the sidebar updates immediately when a task's tags change.
- ✏️ Renaming a note — renaming no longer briefly shows the note as deleted in canvas cards and other views.
- 🎯 Card placement — cards from the Add card picker tile out from the centre of your view instead of stacking, and the picker dims the canvas behind it.
- 🔎 Add card search — the picker finds every calendar event regardless of date, matches accented titles, and no longer hides notes when files share the search term.
- 📐 Shape library — the Excalidraw shape library persists in your vault and file import works again.
- 🔑 Sign-in stability — a dead session no longer triggers a storm of refresh attempts, and sync connections renew in place instead of reconnecting.
- 🚪 Cleaner quit — background embedding work now stops on quit so updates can install.
