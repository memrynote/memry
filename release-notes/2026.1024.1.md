## New Features

- 📚 Readwise integration — Connect Readwise from Settings → Import to preview and import your highlights and Reader documents as notes, which then stay up to date automatically or on demand with Sync now.
- 📅 Readwise in your journal — Optionally see your Readwise highlights in the journal, day by day.
- 🌀 Portals — Embed a live, two-way copy of another note, a block or a search inside any note.
- 🪜 Note summary levels — Fold a note down to its Brief, Key, Takeaway or Topic level.
- 📝 Sticky capture — Press Cmd/Ctrl+Shift+M from any app to jot something down and send it to a note, a task or today's journal, with unsent drafts kept on the edge of the screen and synced to your other desktops.
- ⌨️ Command palette — Press ⌘P (Ctrl+P on Windows and Linux) to search for any action and run it from the keyboard.
- 👋 First-run setup — New installs open with a short setup for your theme, modules, imports, agent and sync, and signing in on another computer brings your vault down directly.
- 🗓️ Day timeline — Plan your day from the side panel by dragging tasks from lists or notes onto today's timeline, stretching them into time blocks, or dragging them back to unschedule.
- ⏱️ Task duration — Tasks can now have an optional duration.
- 🔎 Semantic search — Search now finds notes by meaning as well as by exact words, including long notes, images, PDF pages and voice memos.
- 🏷️ Note aliases — Give a note other names that links resolve to and that sync across your devices.
- 🔗 Unlinked mentions — See notes that mention the current note without linking to it, listed under backlinks, and link them with one click.
- 🔽 Collapsible headings — Click the chevron beside a heading to hide everything under it until the next heading of the same level.
- 💬 Collapsible and custom callouts — Callouts can now be collapsed, and you can define your own callout types, which sync with your settings.
- 🖼️ Image lightbox — Open note images in a viewer where you can zoom and pan.
- 🃏 Note link display modes — Show a linked note at different sizes, with its cover, or as a preview.
- 🔐 Locked Apple Notes import — Import password-protected Apple Notes using your Notes password.
- 🗂️ Safer Obsidian opening — Memry offers to copy an Obsidian vault before opening it.
- 🎨 Home board covers — Add covers to your home board, synced across devices.
- 📆 Link notes to events — Link notes to calendar events straight from the event card.
- ✅ Multi-select in the sidebar — Select several notes in the sidebar tree and act on them together.
- ⚡ Per-folder new-note shortcuts — Assign keyboard shortcuts that create a new note in a specific folder.
- 🖼️ Gallery covers — Gallery view cards now show note covers.
- 📋 Project All tab — A project's All tab lists its notes, tasks and events together.
- 📊 Timeline subtasks and milestones — Fold subtasks under their parent on the project timeline and resize milestones by dragging.
- 🎯 In-note matches — Search lists every match inside a note and opens it at the match you pick.
- 🚦 Status from tasks — A note's Status now follows the tasks in it, and the folder view shows the same value, while a status you set yourself stays until a task changes.
- 🧾 Tasks in the folder table — A note's tasks now show beneath its row in the folder table.

## Improvements

- ⏸️ Clearer sync pause — A pause now shows as Paused everywhere, survives a restart, and Sync Now ends it and tells you why when nothing could be sent.
- 🟠 Waiting-changes warning — The sync icon turns amber when changes have been waiting for more than 15 minutes.
- 🔄 Faster catch-up sync — Sync now fetches only the few items a device is missing instead of re-reading the whole vault, so it no longer sits in "Syncing" for long stretches.
- 🥇 Better search ranking — Notes with your words side by side now rank first, and regular notes appear before files read with OCR.
- 🔤 Auto-closing brackets — Typing ( or [[ in the editor now adds the closing bracket for you.
- 📑 Tasks in note order — Tasks grouped by note now appear in the same order as in the note.
- 📄 PDF display choice — Show a PDF in a note either embedded or as its file name.
- ✏️ Naming new notes — A new note is now named from its title field instead of the sidebar row.
- ↩️ Scroll position on back and forward — Going back or forward returns you to where you left a note.
- 🗑️ Deleting parent tasks — You're now asked what to do with subtasks when you delete a parent task from the task drawer.

## Fixes

- 🪟 Windows taskbar grouping — The Memry window now groups under its pinned taskbar icon on Windows.
- 📁 Case-only folder renames — Renaming a folder by changing only its letter case now works on Windows.
- 🧭 Tabs in narrow windows — The first tab no longer overlaps the window controls in narrow windows.
- ✔️ Duplicate task rows — Fixed duplicate, overlapping rows in the Tasks list after a parent task was completed by finishing its subtasks.
- 📝 Remote edits in the editor — Changes from your other devices now reliably appear in an open note.
- 💾 Unsynced text preserved — Text that hadn't synced yet is no longer lost when a sync fills in the same note.
- ⚠️ Oversized sync changes — Changes too large to sync now fail once with a visible error instead of retrying silently.
- 🏷️ Tag sync and renames — Tag definitions now merge correctly during sync, pins are kept, and tag chips update right after a rename.
- 🔗 Wiki links in synced notes — Wiki links typed as plain text in synced notes are now found for backlinks.
- 🧱 Editor selection typing — Typing over a block selection now replaces it as expected.
- 📐 Editor menus — The block-type dropdown no longer scrolls the note, and the @ menu opens below the cursor when there is room.
- 📊 Table cells — Table cell alignment now works and is saved correctly.
- 📄 Embedded PDFs — Embedded PDFs can grow back after being shrunk.
- 🔗 Long URLs in tasks — Long URL values now stay inside the task drawer card.
- 🗃️ Property safety — Property edits are blocked while the property file can't be read, and bulk field fill waits until all rows have loaded.
- 🔍 Search index repair — The search index now repairs itself after corruption.
- 🛡️ Background processing stability — Text recognition and search indexing now pause instead of crashing repeatedly.
- 📎 Attachment uploads — Empty attachments are no longer uploaded, and uploads stop retrying on a device that has been removed.
- 📆 Calendar sign-in errors — An unreadable saved sign-in no longer causes errors in the calendar.
- 📚 Readwise edits respected — A highlight you delete from an edited Readwise section stays deleted, and Reader articles keep their images and captions.
