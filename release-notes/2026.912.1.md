## New Features

- 📝 Themed code blocks with a toolbar — Code blocks now follow your app theme and font size, with a copy button and an alphabetical language picker that includes PowerShell and KQL.
- 📎 Reuse an attachment across notes — Embed a file the vault already stores in another note with `/existing attachment`, and deleting it keeps the file while any note still references it.
- 🔍 One picker for every file command — `/image`, `/media`, `/pdf` and `/file` now open the same search-first, fully keyboard-driven palette for uploading a new file or reusing an existing one.
- 🏷️ Multi-tag filtering you can save — Ctrl-click or Cmd-click tags in the sidebar to narrow a tag page to items carrying all of them, and save the combination as a named search that survives a restart.
- 🔗 Relate notes to canvases and journal entries — Relation properties can now point at canvases and journal days, and clicking a chip opens that board or that day's entry.
- 📅 Upcoming days in the journal widget — The Home journal widget now shows today and the next three days, with a preview for days you have already written.
- 🗂️ Keyboard-driven vault switching — Press Cmd+Shift+O to open the vault switcher on your current vault, then move with the arrow keys and switch with Enter.
- 🔖 Tag suggestions and middle-click in folder views — A `Tags` filter suggests your most-used tags as you type, and middle-clicking any row opens it in a background tab.
- 🎨 Set an icon from the folder tab — Right-click a note row in a folder opened as a tab to set or remove its icon.

## Improvements

- 🔔 Quieter update notices — A new version now waits as a single sidebar line instead of interrupting you with a dialog, so you can see what changed and restart now or on your next quit.
- 🪟 Smoother Windows updates — Windows installs now update through a more reliable, properly signed packaging system.

## Fixes

- 🖼️ Folder icons no longer shrink — Custom folder icons added from a URL now render at the same size as the built-in folder icon in the sidebar and folder view.
- 🗺️ Wiki links can name a canvas — Type `[[` to pick a canvas, click the link to open the board, or copy a canvas's link from its sidebar menu.
- 🛡️ Editing attachment rows no longer corrupts files — Tag and property cells are now read-only for PDFs, images, audio and video in folder tables, since only Markdown notes can store them.
- 🔗 Pasted links keep their list item — Pasting a bare URL into a bulleted or numbered list no longer removes the bullet, and the link can be selected, copied and edited like ordinary text.
- ⏰ Journal reminders open their own day — Clicking a journal reminder in a toast, a system notification, or the inbox list now opens the day it was set for instead of today.
- 🔄 The journal widget stays current — Home now picks up new and edited journal entries on its own, including ones written in another tab, on another device, or outside Memry.
- 🎯 Icon pickers stay on screen — The note, folder, canvas and tag icon picker no longer opens with its tabs cut off, and it stays put while the sidebar list scrolls underneath.
- ⬇️ Working download link after a failed update — The failed-install dialog now points at the real download page instead of one that no longer existed.
