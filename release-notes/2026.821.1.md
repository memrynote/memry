## New Features

- 🧠 Note mind map — turn any note's headings into an interactive map from the note header, with links, lists, tasks and containers branching out.
- 🗺️ Jump between map and note — click a mind map node to land on that spot in the note, and follow wiki links straight to the notes they name.
- 🧰 Mind map toolbar — fit, zoom and copy the map from its own toolbar, with very large maps folded so they stay readable.
- 🎨 Save a mind map as a canvas — keep the map as an editable canvas that still names where each card leads when you point at it.
- 📄 PDF viewer toolbar — one toolbar for PDFs with a page number you can type into.
- 📜 Scroll through embedded PDFs — an embedded PDF now scrolls the whole document instead of stopping at the first page, with a page indicator on hover.
- 🏠 Recently Opened widget — a Home widget for the notes you read but never edited, sitting beside Recently Edited.
- 📋 Project widget on Home — pin a project to your board and see its overview, tasks, notes, files and events without leaving Home.
- 🗂️ Manage your Home boards — rename, reorder and delete boards from a new manager dialog, synced to your other devices.
- 📅 Per-weekday journal templates — pick a different starting template for each day of the week from Settings or the sidebar.
- 🖼️ Custom icons for folders and notes — set an image icon from your machine or a link, stored with your vault.
- ↕️ Reorder and sort the sidebar — drag sidebar sections into your own order and choose a sort mode for each, synced per vault.
- 🔤 Use any installed font — pick any font on your machine for the app interface.
- 🗃️ Richer tables — put images in cells, colour cells, and reach row, column and cell menus from handles on the border lines.
- ⌨️ Table actions from the keyboard — add and remove rows and columns without touching the mouse.
- 🧭 Finder-style sidebar navigation — arrow keys step through the notes tree, opening, closing and moving between folders.
- 🪟 Tab click behaviour — choose whether a plain click reuses the current tab or opens a new one, applied everywhere, plus open a sidebar row in a new tab or beside the current one.
- 🔗 Link to a spot inside a note — memry:// links and wiki links can point at a heading, and any link can carry its own name.
- ✅ Task due-date filters — scope your task list by due-date window and find work with no date at all.
- 🔄 Check for updates from the menu — available on every platform.
- 📆 Connect Google Calendar in Settings — calendar setup now lives under Settings → Calendar.

## Improvements

- ⚡ Faster catch-up after reconnecting — sync now works through open notes first and paces its checks separately from its updates.
- 🎯 Snappier Home board — the board paints immediately instead of fading in.
- 📑 PDFs open fitted to the pane — and an embedded PDF's resize handles are visible again.
- 🎨 Clearer text colours — the editor's colour palette was recut for better contrast.
- 🔍 Clearer sync errors — a failed sync now reports the actual status and server reason instead of a blank label.
- 📓 Journal jumps to headings — the journal uses the main editor and supports jumping to a heading.

## Fixes

- 💾 Edits survive quitting — closing the app saves your latest changes instead of dropping them.
- 🗂️ Tabs come back after a restart — instead of collapsing to Home.
- 🗑️ Deletes made offline still travel — a delete performed while sync is down reaches your other devices.
- 📝 Note bodies stay intact — a note is no longer emptied when its collaborative copy serializes as blank.
- 📎 Attachments survive a second device — embeds are written relative to their note, and moving a note rewrites the references it carries.
- 🖇️ No more repeated attachment requests — the app stops re-asking the server for files it does not have.
- 🏷️ Hashtags in the body survive a remote update.
- 🔁 Local-only notes stay local — and toggling sync mid-save no longer strands buffered changes.
- 🔎 Search repairs itself — a damaged search index is rebuilt instead of returning nothing.
- ✏️ Inline rename stays open — renaming a note or folder from the sidebar menu no longer loses the name field.
- 📍 New and renamed sidebar items stay put — instead of jumping somewhere else in the list.
- 📁 Folder fixes — an empty folder accepts a dropped folder, and renaming a folder no longer leaves a duplicate behind.
- 🧾 Tables get their header row immediately — no reload needed, and you can toggle the header row or column from the handles.
- 📋 Pasting into a cell behaves — plain text stays text, and a pasted URL becomes a mention instead of erroring.
- 🔽 Toggle blocks survive a save — they now have a markdown form of their own.
- 🔗 Wiki links resolve everywhere — `Note#Heading` works in previews and exports, and `[[…]]` links are recognised when a collaborative note is opened.
- 🖌️ Canvas fixes — the camera stays where you left it, deleted canvases close their tabs, tab titles track the real name, and images stay inline while signed out.
- 📐 Large canvas warning once — a too-large-to-sync scene is announced once instead of on every autosave.
- ▶️ YouTube embeds play in the packaged app — instead of failing with Error 153.
- ✅ Task list refreshes without a restart.
- 🧷 Formatting toolbar on narrow notes — the sticky toolbar no longer breaks.
- 🔄 More reliable updates — an update check survives an expired download link, being offline reads as a warning rather than an error, and Windows updates no longer abort on a running binary.
- 🕘 History warnings you can act on — the app now tells you when note history stops being kept instead of quietly retrying.
