## Improvements

- 🔗 Linking devices needs a sync plan — On a free account, Link new device now explains that you need a sync plan instead of showing a code that would only open an empty vault on the other device.
- 🔍 More relevant semantic search — Semantic search now hides weak matches, so you see fewer unrelated results.
- 🧠 More reliable search indexing for long notes — Very long notes are now indexed for semantic search without failing.

## Fixes

- 📁 Case-only folder renames — Renaming a folder by changing only its capitalization no longer creates a duplicate folder and duplicate notes on macOS and Windows, and vaults that were affected clean up the duplicates on this device when they open.
- 🔐 Staying signed in — Sync no longer signs you out after the app has been busy for a while.
- 💳 Account deletion cancels your subscription — Deleting your account now also cancels your Paddle subscription.
- 🗂️ No more empty extra vaults — Sync no longer creates an empty extra vault in the background.
- 🛡️ Safer note frontmatter — Memry now refuses frontmatter that tries to run JavaScript when it reads notes.
- 🏷️ Link mentions stay intact — Link mentions inside styled text, mentions rebuilt by edits made outside Memry, and mentions edited on two devices now show up correctly as a single chip.
- 📂 Notes that can't follow their folder — When a linked note can't move along with its folder, Memry now tells you and refreshes the sidebar tree.
- 🧱 Option-dragging blocks out of portal windows — Option-dragging a block out of a portal window now keeps the original block in place.
- 🌍 Missing translations — The messages for unreadable views, portal blocks and device linking now appear in every supported language.
