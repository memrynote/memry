## Fixes
- 🔑 Keychain freeze — an unresponsive system keychain no longer stops the journal, file and project pages from loading or leaves diagnostic reports stuck on "Sending…".
- 🧵 Stuck keyring recovery — keychain requests are now handled one at a time, so a wedged system keyring can no longer tie up the rest of the app.
- 🕸️ Graph view without a GPU — the graph now renders with software rendering on machines without GPU acceleration, and tells you when acceleration is missing.
- 🩺 Clearer startup errors — when the local database cannot be opened at startup, the app now reports the underlying error instead of failing quietly.
