## New Features

- 📓 **Journal header actions**: The journal header now has the same actions as notes, plus an overflow menu.
- 📅 **Weekday in journal filenames**: Add the weekday to journal filenames with `dddd` (Saturday) or `ddd` (Sat) in Settings > Journal > Date Format, and changing the format now renames your existing journal files to match.
- 🗂️ **Vault icons and plain checkboxes**: Vaults can now have icons, notes support plain checkboxes, and the agent interface has been refreshed.
- 🤖 **Review agent edits in place**: You can review changes the agent makes to notes and journal entries right inside the note.
- 🧩 **Agent HTML artifacts**: The agent can add interactive HTML artifacts to your notes, and they run in a safe, sandboxed frame.
- ✅ **Approve every agent write**: Before the agent changes anything in your vault, it asks you first and shows a real preview of the change.
- 🛰️ **Antigravity CLI in Agent Chat**: You can now choose Antigravity CLI as a backend for Agent Chat.
- ✨ **Google Gemini for inline AI**: You can now use Google Gemini as the provider for inline AI editing.
- ⌨️ **Rebindable shortcuts**: You can rebind every tab, split and zoom shortcut in Settings > Shortcuts, and tab, split and vault shortcuts now work while you type in a note.
- 🎨 **Color themes**: Pick a color theme for the app, switch the folder layout, and reorder sidebar sections.
- 📝 **Edit tasks inline**: You can edit every task property directly in notes and the journal, with property chips on each task, quick-add shorthand like `#tag @friday !high`, and single-key pickers.
- 🍎 **macOS Calendar**: On a Mac, you can see calendars from the built-in Calendar app (iCloud, Google, Exchange, On My Mac) without signing in; they are read-only, stay on that Mac, and are never synced.
- 🗓️ **CalDAV calendars**: You can now connect CalDAV calendars.
- 🔗 **Calendar subscriptions**: Subscribe to read-only calendars with an ICS or webcal link, then rename them, change their color and get help finding the link.
- 📊 **Gantt Timeline view**: The calendar has a new Timeline view that lays out your schedule as a Gantt chart.
- 🖼️ **Embed HTML files**: Attached HTML files can be shown inside a note in a safe, sandboxed frame.
- 🖌️ **Whiteboard block**: Add a whiteboard directly inside a note, or mention and embed an existing canvas with @.
- 🧮 **Math and Mermaid blocks**: The editor now has a math block with proper formula rendering and a block for Mermaid diagrams.
- 🗃️ **Collections view options**: Choose to list notes before folders, hide files like PDFs and images from the sidebar tree, keep section headers pinned while you scroll, and expand or collapse a folder with everything inside it.
- 📋 **Vault activity log**: Settings > Vault now has a log of the files Memry added, removed or skipped, what each import brought in, and anything that failed to sync.
- 🧷 **Live canvas cards**: You can place projects and filed files on a canvas as live cards.
- ↗️ **Outgoing links**: A note's outgoing links now appear next to its backlinks.
- 😀 **Set note icons in bulk**: Set a note's icon from the Notes list, including for several selected notes at once.
- ➕ **New note from this note**: You can start a new note directly from the note you are reading.
- 🧭 **Group tasks by source**: Tasks can be grouped by the folder and note they come from.
- ✏️ **Name items where they appear**: New notes and folders can be named right where they are created.
- ⏳ **Task date distance**: Tasks show how far away their dates are.
- 👆 **Swipe between vaults**: Swipe in the sidebar to switch between vaults.
- ⚙️ **Redesigned settings**: Settings are organized into grouped pages and can be searched.
- 🚪 **Clearer vault setup**: Getting started now has separate steps for creating, opening or syncing a vault.
- 📥 **Better Apple Notes import**: Choose which Apple Notes folders to import, bring tables over as real tables, and see which locked notes were skipped.
- ☑️ **Checklists become tasks on import**: Checklists in imported notes become real tasks, with checked items already completed and one level of subtasks kept.
- 🌈 **Google Calendar colors**: Calendar events can use Google Calendar's color palette.

## Improvements

- 🧰 **Single-row toolbar**: The editor formatting toolbar now fits on one row, with extra options in an overflow menu.
- 🎨 **Easier-to-read calendar**: Calendar colors are brighter and look the same in light and dark mode, longer events show their time and length, and tasks can be completed or rescheduled in one click from the calendar.
- ⚡ **Instant Google Calendar updates**: Changes you make in Google Calendar now show up within seconds instead of taking up to 5 minutes.
- 🚀 **Faster sync**: Note contents and other changes arrive sooner, and setting up a new device takes less waiting.
- 🔁 **More dependable sync**: Pending changes to notes, tasks and projects are saved safely, so they survive restarts and interruptions.
- 🌐 **Global Capture without Accessibility**: Global Capture shortcuts on macOS no longer need Accessibility permission.
- ⚠️ **Shortcut conflict warnings**: When a Global Capture shortcut clashes with another app, Memry tells you and keeps the binding that still works.
- 🧠 **Smarter AI**: Inline AI works with newer Claude models, and the agent picks the right task and folder filters more reliably.
- 💳 **Upgrade prompt instead of an error**: Accounts without a paid plan now see an upgrade option instead of a sync error.
- 📄 **Apply Template from the menu**: Apply Template is now available in the note page menu.
- 📁 **Projects follow the note**: Tasks you create in a note are filed in that note's project, and when you set a note's project Memry offers to move the tasks already in it.
- 🪄 **Empty folders sync**: Empty folders now sync between your devices.

## Fixes

- 🔒 **Vaults stay with their account**: When you sign out, the next account on the same computer can no longer sync your vaults, and a vault with notes your account hasn't seen yet asks before it syncs.
- 🔄 **Items no longer go missing between devices**: An item created on one device now reaches another device even if both were syncing at the same moment, and affected devices re-download their data once to fix it.
- 🧾 **Nothing lost after updates**: When this version can't read a synced item yet, sync keeps it and tries again after the app updates.
- 🗑️ **Deleted notes stay deleted**: Notes you deleted no longer come back after syncing or when you set up a new device.
- ♻️ **Recreated items stick**: Deleting something and creating it again no longer gets undone by the earlier delete.
- 📱 **Signing in on a second device**: A second device now uses your account's existing vault instead of starting a separate one.
- 🗂️ **Clean vault switching**: Switching vaults no longer briefly shows the other vault's notes, and the vault switcher now reflects vaults that were removed or went missing.
- ⌨️ **Typing saved to the right place**: Text typed just before switching journal days or notes is saved where you typed it, the last keystrokes before closing a tab are kept, and template edits made just before switching tabs are no longer lost.
- 📏 **Spacing around quotes kept**: Blank lines above and below quotes and callouts are no longer removed when a note is saved.
- ☑️ **More reliable tasks in notes**: Checklist lines reliably become tasks, choices made while creating a task are kept, checkboxes keep their links and styles when they become tasks, and a task line's formatting survives when the note is reloaded.
- 📆 **Journal tasks link back**: Tasks created in a journal day now link back to that day instead of opening a blank document.
- 🔁 **Recurring tasks**: Tasks set to repeat from their completion date now schedule the next occurrence correctly.
- 🧩 **Templates**: Templates no longer carry task IDs into the notes created from them.
- 🔗 **Project links preserved**: Links between notes and projects now sync correctly and are kept even when a note's properties are not read.
- 🪟 **Moving folders on Windows**: On Windows, you can now move a folder that contains subfolders.
- 😀 **Icon picker stays open**: The Set Icon picker no longer closes when a menu fades out.
- 🔐 **Sign-in code kept**: The sign-in code you typed is no longer cleared while the countdown runs.
- 🍎 **Apple Notes folder structure**: Nested Apple Notes folders keep their structure when imported.
- 🏠 **Home board and tour**: The home board is set up only after your first sync finishes, and the first-run tour no longer reappears in vaults you have already used.
- 🏷️ **Small editor fixes**: This release fixes inline tags, the journal month list, the @now shortcut, graph labels, image resizing and the tag hub drag preview.
