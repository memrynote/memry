## Improvements

- ⚡ Faster first sync — Setting up Memry on a new device now downloads your notes and data in larger bundles, so the first sync finishes much sooner.
- 🚀 Quicker sync updates — Incoming changes are now saved in larger batches, so syncing big vaults is faster and more reliable.
- 🌐 Fewer sync requests — Memry no longer asks the server for note snapshots that don't exist, which cuts down on unnecessary network traffic.

## Fixes

- 🔗 Note links in task titles — Links to notes in task titles are now kept and shown correctly.
- 📝 Note content preserved — Notes that already exist on the server are no longer recreated from local markdown, so you won't lose newer content.
- 📁 No more duplicate files — Files synced into folders whose names differ only in capitalization now match the existing file instead of creating a copy.
- 🔄 Interrupted first sync resumes — A first sync that gets interrupted now picks up where it left off, and a slow sync is no longer mistaken for a stuck one.
- 🔐 More reliable sync sessions — Sync sessions now close and renew correctly during the initial download.
