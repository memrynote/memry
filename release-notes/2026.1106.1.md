## Fixes

- ✅ Done tasks stay done — Opening a note with an outdated checkbox no longer reopens a finished task, and only checkboxes you edited outside the app change a task.
- ⏰ Fired reminders stay fired — A reminder that went off on this device no longer comes back when another device syncs its older copy.
- 📅 Calendar sync per device — Each device keeps its own Google Calendar sync position instead of picking up another device's.
- 🧩 Portals follow dragged blocks — Dragging a block out of a portal window now moves the portal with it.
- 🔗 Link mentions keep their look — Link mentions stay rich and are no longer duplicated after a note is reloaded from disk.
- ✏️ Empty-line placeholder in place — The placeholder on an empty block now sits at the start of the line.
- 🔤 Interface font in dark mode — The note editor uses the interface font you chose in dark mode too.
- 🖱️ Popovers work inside dialogs — Clicking a popover that opens inside a dialog now works.
- 🪟 Windows title bar buttons — The minimize, maximize and close buttons match the title row size when the app is zoomed.
- 🧠 Embedding model status — The embedding model shows as Downloaded when its files are on disk, even after the idle worker stops.
- 🦙 Clearer Ollama errors — Agent chat shows the reason the Ollama server gave instead of a bare Bad Request.
