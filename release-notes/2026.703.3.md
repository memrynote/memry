## New Features

- 🔔 In-app update prompt — get a cleaner in-app prompt for updates instead of the native system dialog, with options to skip, remind, or download.
- 🔤 Font size scaling — editor text and tags now scale with your Appearance font size setting for more comfortable reading.

## Fixes

- 🩹 Editor crash on empty blocks — notes with missing block ids are now repaired automatically so the editor no longer crashes.
- 🪟 Windows window visibility — the main window is now guaranteed to appear on startup on Windows.
