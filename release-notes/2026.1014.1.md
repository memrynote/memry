## New Features

- 🏷️ **Tags with fields** — Tags can now have fields like Company, Role or Email that appear on every tagged note, along with relation fields, @ mentions, a "Linked here" section, AI fill-in for empty fields, and ready-made Person, Company, Meeting and Book tags.
- 🔍 **Redesigned search** — Results stay on one line with a preview of the selected item beside them, and you can type `/` to filter by type or date or `#` to pick a tag right in the search field.
- 📄 **Search inside PDFs and images** — Memry now finds PDFs, images and screenshots by the text inside them, reading that text on your device with OCR support for languages beyond English.
- 🔒 **Lock notes and folders** — Make notes, folders or journal entries read-only so the editor, agents and outside tools can't change them.
- ✂️ **Crop images** — Crop an image inside a note without changing the original attachment.
- 🧱 **Column layouts** — Put blocks side by side in up to five columns, saved in a format Obsidian's Multi-Column Markdown can read.
- 💬 **Nine new callout types** — Callouts come in nine more styles, each with its own colour and icon.
- 📝 **Footnotes** — Footnotes show as numbered markers in the editor and are included when you export.
- ✅ **Nested subtasks** — An optional setting lets you nest subtasks as deep as you like.
- ✍️ **Writing tools** — Get alternative phrasings, inline ghost suggestions and a Lab area for writing help, all available from the editor's context menu.
- 📊 **Property charts** — Chart how journal and note properties change over time.
- 📋 **View blocks** — Embed a live list of notes inside any note.
- 🧠 **Similar notes and suggestions** — Local AI suggests similar notes, tags and canvas groups without anything leaving your device.
- 🕸️ **Graph editing** — Alt-drag one note onto another to link them, add tags by right-clicking, save graph views, and pin dragged nodes so the layout stays put.
- 🎨 **Smarter canvases** — Tie canvas sections to a tag or property so dropping a card applies it, add a whole tag, folder or saved view in one go, and canvas arrows now count as backlinks.
- 🗂️ **Filter tasks by location** — Filter tasks by folder or note, or right-click either one in the sidebar and choose Show Tasks.
- 🔗 **Folder-path wiki links** — Wiki links can now point to notes by their folder path in the vault.
- 📅 **Reschedule events in month view** — Drag calendar events to new times in month view and in all-day rows.
- 🎙️ **Voice transcription language** — Pick the language voice transcription should listen for.
- 🎲 **Random line template variable** — Use `{{random-line:Note}}` in a journal template to pull in a random line from a note.
- 📓 **Journal folders** — The journal folder now shows in the sidebar, can be split into year and month folders, and keeps working if you rename it.
- ☁️ **Per-note sync status** — See whether a note's latest text has reached the server.
- 🤖 **Agent chat upgrades** — Attach small text files, queue up messages while the agent is still replying, set reasoning depth or turn thinking off, continue past the step limit, and let agents look at images and PDF pages in your vault.

## Improvements

- ⌨️ **Day panel shortcut** — Press Cmd+Shift+B to show or hide the right day panel.
- 🪟 **Task details in place** — Clicking a task's arrow in a note or journal opens its details panel right there.
- 🏠 **Default Tasks project** — Choose which project Tasks opens on, either from the project picker or from the project's edit dialog.
- 📐 **Better tables** — Pick a table's size when you insert it, and add or delete several rows or columns at once.
- 🖼️ **Image and cover controls** — Resize images by dragging any corner, and adjust a cover photo's focus, zoom and band height.
- 📋 **Copy from the block menu** — Copy one block or a whole selection straight from the block menu.
- ☑️ **Checklist setting** — A new setting stops checklist items from automatically turning into tasks.
- 🧩 **HTML blocks and comments** — Text inside HTML blocks is now searchable and linkable, comments are kept intact, and `%%` comments show as a marker and are left out of exports.
- 📦 **Richer callouts** — Callouts can now contain lists, headings and other blocks.
- 🪟 **Windows title bar** — On Windows, the title bar now sits in the same row as Memry's own title row.
- ⚡ **Faster, lighter launch** — Memry uses less memory at launch, especially on Home, and shows a loading spinner instead of an empty pane when a page is slow to open.
- 🧠 **Better local embeddings** — Local AI features now run on EmbeddingGemma 2.
- 🔄 **Quieter sync when signed out** — Sync no longer retries every second while you're signed out, and the app log no longer fills up with one repeated error.

## Fixes

- 🔄 **More reliable sync** — Fixed cases where changes made on another device could be lost (mostly on Windows), where deletes made while the app was closed didn't sync, and where offline edits could get stuck in the queue.
- 🛡️ **No lost text on remote deletes** — If a note or journal is deleted on another device while you have unsent text in it, that text is now saved to your inbox.
- 📁 **Folder sync** — Folders deleted on another device or outside the app are now removed everywhere, and new folders sync properly.
- 🔐 **Staying signed in** — Memry stays signed in through network failures, and devices you've used before can sign in with an email code.
- 📝 **Markdown stays as written** — Links, lists, quotes, line breaks, code blocks and comments now come through saves unchanged.
- 🔗 **Links inside code** — Link syntax inside code no longer adds graph nodes or backlinks.
- 🧾 **Cleaner exports and copies** — PDF and HTML exports and copied blocks no longer include a task's internal id, and copied tasks keep their checkbox.
- 🖼️ **Icons show correctly** — Custom and library icons now show as icons in templates, the gallery, tag chips, projects, graph tooltips and exports, instead of raw text.
- 🔀 **Vault switching** — Stray clicks, scrolls and keystrokes no longer switch vaults by accident.
- 🗑️ **Deleted notes disappear properly** — Home bookmarks and project hubs no longer show notes that have been deleted.
- 💾 **Notes kept safe** — Notes are kept when the vault is briefly unreachable, when a file can't be read, or when iCloud has moved the file to the cloud.
- 🛡️ **Vault boundary protection** — Memry no longer follows links that point to files outside your vault.
- 📅 **Calendar fixes** — Clicking a reminder opens what it's for, all-day task dates survive calendar sync, and disconnected Google calendars stay disconnected.
- 📎 **Attachments and embeds** — Obsidian embeds now load from more locations, and attachment uploads retry automatically every five minutes and on reconnect.
- ⚠️ **Rename warning** — Memry now warns you when a renamed note has the same title as a note in another folder.
- 🧭 **Interface fixes** — Editor submenus stay open when your pointer pauses, the rail dock stays on screen in short windows, and folder view loads every page.
- 🤖 **Agent chat fixes** — Agent chat errors are now shown clearly, DeepSeek can use vault tools, and tools stay on after a brief error.
- 💳 **Billing portal message** — If the billing portal is unavailable, you now get a message that tells you what to do.
- 🌐 **Translations** — Added missing UI translations and fixed machine-translated text.
