## Fixes

- 🔁 Pulled notes stay in sync — A note pulled from another device no longer gets replaced by the local file when the sender's clock runs ahead.
- 📓 Journal days keep their text — A journal day pulled onto a fresh device keeps the text from the server instead of being overwritten by an empty file.
- ✅ Draft tasks stay single — Typing a title while a new task is being created no longer creates a second task for the same line.
